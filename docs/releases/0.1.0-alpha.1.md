# Project Stardust 0.1.0-alpha.1

This is the first public alpha of Project Stardust, an open-source, title-specific recompilation
project for Super Stardust HD (PlayStation 3 title ID NPEA00014).

## Release format

This release provides source and build tools only. It is **not** a portable playable game and does
not contain a prebuilt game executable. The executable produced by the local build includes
translated game code, so no such executable is distributed here.

The attached `ProjectStardust-0.1.0-alpha.1.zip` contains the source project, required open-source
source submodules, documentation, licenses, tests, and build scripts. It does not contain game or
firmware files, extracted keys, generated game code, saves, logs, caches, vendor SDKs, or PlayStation
artwork.

## Building

Users must provide their own lawful copies of the supported, updated decrypted `EBOOT.ELF` and PS3
system software 4.93 `PS3UPDAT.PUP`. Run `run.cmd` and select those files. The builder validates
them and generates the game locally. See [Getting your files](../getting-files.md),
[Building](../building.md), and [Privacy](../privacy.md).

## Verification and known limits

- Python test suite: 1,275 tests run; 56 skipped and the remainder passed.
- Windows CTest run: 52 tests; 2 optional tests skipped and the remainder passed.
- `game_boot` passed with user-provided inputs.
- A full playthrough and complete graphics compatibility have not been verified.
- Wider-than-16:9 gameplay view is not implemented in this alpha.

This software is experimental. A successful build or boot does not guarantee a complete playthrough.
